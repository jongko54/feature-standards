# v0.3 계정 생명주기·PostgreSQL TLS

승인된 다음 고도화 항목을 구현한다. 기본 v1/v2를 유지하고 선택 v3/schema2로 가입·확인·비밀번호 재설정을 추가한다. 외부 메일 발송과 운영 배포는 포함하지 않는다.

1. 주 에이전트가 v3 계약·명시적 schema2 migration·공유 DB 원자 연산과 테스트 fixture를 구현한다.
2. Python/Go 담당과 Java 담당이 각각 HTTP/설정/저장소 경계를 확장한다. Rust 담당은 검증된 원격 TLS를 먼저 구현하고 같은 v3 어댑터를 추가한다. 에이전트는 지정 구현 디렉터리만 편집하고 별도 fixture DB를 사용한다.
3. 주 에이전트가 React 가입·확인·재설정 화면, 로컬 메일 수신 도구, 공통/mixed/race/실패/browser 검증과 OpenAPI·CI를 연결한다.
4. 독립 검수 후 실제 로컬·원격 검증을 통과한 변경만 커밋·푸시한다. 원격 SHA와 Actions 결과를 확인한다.

schema2의 generated enabled가 미확인·관리자 비활성 계정을 모든 바이너리에서 차단한다. token/사용자 잠금 순서, 구 password 로그인 경합, 민감한 outbox와 실제 발송 경계를 검수한다. 작업 전용 loopback DB와 임시 TLS 서버만 시작·종료하며 운영 DB와 외부 수신자에는 접근하지 않는다.
