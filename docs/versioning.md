# 계약 버전과 업데이트

저장소 릴리스 `0.1.x`와 계약 이름 `browser-session-v1`은 다릅니다. 계약은 외부 동작을 식별하며, 릴리스는 명세·구현·클라이언트·적용 지침의 묶음을 식별합니다. 초기 버전은 실험적 상태이며 호환성 변경을 릴리스 노트에 명시합니다.

같은 계약의 구현은 엔드포인트·상태 코드·오류 코드·세션 무효화·보안 전제에 합의해야 합니다. 내부 함수, 프레임워크, 저장소 인터페이스는 서로 달라도 됩니다. 기존 호출을 깨뜨리는 계약 변경은 새 프로필로 정의하고 이전 규격을 조용히 덮어쓰지 않습니다.

복사해서 통합하는 프로젝트는 출처 URL, 통합한 커밋 SHA, 프로필, 수정한 지점, 실제 검증 명령과 결과를 해당 프로젝트 문서에 남깁니다. 이 레포의 업데이트가 복사본에 자동 전달되지는 않습니다. 새 변경을 비교하고 보안 수정 여부를 검토한 뒤 회귀 테스트로 반영하세요.

런타임과 라이브러리는 각 구현의 잠금 파일을 기준으로 합니다. 버전 업데이트 시 자체 테스트와 공통 API 테스트를 실행하고 클라이언트와 관련되면 양쪽 서버 대상 브라우저 검증도 실행합니다. 지원 언어를 추가했다는 표시는 실제 테스트 결과가 있는 경우에만 합니다.
