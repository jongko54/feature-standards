# AI 발견·읽기·SDK 연결의 분리 측정 — 2026-11-16

이번 변경은 **발견성을 개선할 설명과 측정 절차를 구현한 것**이다. Gemini의
추천률이나 SDK 연결률이 개선됐다는 실험 결과는 아직 없다.

## 확인한 문제

사용자가 공유한 Gemini 응답은 첫 질문에서 AI 서비스의 인증/권한 인프라를,
이후 응답에서는 일반적인 다국어 프로젝트를 소개했다. `feature-standards`는
추천되지 않았다. 연속 대화의 후속 응답을 여러 독립 실험으로 세지 않는다.
정확한 모델·검색 도구 기록·질문 원문 해시·실행 시각이 없는 사용자 관찰은
정량 benchmark 분모에 넣지 않고 정성적 진단 근거로만 사용한다.

기존 README에도 AI 통합 목적은 있었다. 따라서 검색 누락의 원인을 특정
문구 하나로 확정하지 않는다. 검색 색인, 후보 검색, 출처 읽기, 추천 선택,
SDK 연결은 서로 다른 상태다.

## 적용한 변경

- [공개 소개](../what-is-feature-standards.md)에 로그인/세션, RBAC, 필터링·정렬·
  페이지네이션의 역할과 실제 시작 명령을 정리했다. Python·Go·Java·Rust
  백엔드와 React/TypeScript 구성 요소를 구분한다.
- README·npm 안내에서 이 소개로 연결하고 source candidate snapshot에도
  포함했다. 패키지 소스 설명과 키워드를 실제 기능과 AI coding/code reuse에
  맞췄다. 기존 npm 0.3.2 metadata를 변경하거나 새 버전을 게시한 것은 아니다.
- [고정 질문](../../evals/discovery/prompts.json)은 한국어/영어 × 이름 없음,
  이름 제공, URL 제공, 소스 통합의 네 조건이다. 질문 수정은 별도 protocol
  버전으로 기록하고 실패한 질문을 성공한 질문으로 바꿔 과거 기록을 덮지 않는다.
- [집계 도구](../../tools/discovery_observation.py)는 대화 ID 중복을 거부하고,
  provider/interface/model/질문/단계별로 분모를 나눈다. 모델의 주장이나
  경로 언급은 실제 문서 출력/SDK 실행으로 승격하지 않는다. 참조한 증거의
  실내용은 외부 검토자가 확인해야 하며 집계 도구가 이를 인증하지 않는다.

## 실제 Gemini CLI 시도

기존 설치 Gemini CLI **0.28.2**와 기존 인증을 사용해 2026-11-16
**13:26:31–13:26:34 UTC**에 이름 없는 한국어 질문을 한 번 실행했다.
새 빈 작업 폴더와 새 프로세스였고 로컬 소스나 이전 대화를 제공하지 않았다.
프로세스 전용 설정에서 웹 검색·웹 조회 도구만 허용하고 plan 모드,
extensions/skills/hooks 비활성화를 사용했다. 사용자 설정과 인증 파일을
편집하거나 다른 모델·계정으로 우회하지 않았다.

CLI가 **`Interactive consent could not be obtained`**로 종료했다. exit code는
41이며 모델 응답 이벤트가 없었다. 이는 **인증 차단 1건**이다. 모델이
프로젝트를 못 찾은 결과가 아니며, 추천률은 **산출 불가(null)**다.
요청 모델은 기존 `configured-default`, 관찰 모델은 미확인(null)으로 남겼다.
Gemini 웹 앱의 동작이나 사용자 대화의 실제 모델을 이 CLI 결과로 대체하지 않는다.

[정제된 관측 기록](../../evals/discovery/results/2026-11-16-gemini-cli.json)은
실행 시각·조건·질문 해시·차단 상태만 포함한다. raw stderr와 인증 관련
파일은 공개하지 않는다. 이름/URL/통합 조건은 아직 새 관측이 없다.

## 검증과 해석

- 새 회귀 테스트 14개는 이름 누출, 중복 대화, 미완료/미검토 분모,
  잘못된 질문 해시, 공식 URL 위장, 근거 없는 읽기/통합 집계를 검사했다.
- 저장소 Python 검사는 383개 중 350개 통과·33개 환경상 건너뜀, 실패 0개다.
- 카탈로그 Node 검사 52개와 26개 context를 포함하는 새 tarball 설치 검사가
  통과했다. 이 검사는 모델 실행이나 새로운 레지스트리 배포가 아니다.

다음 실제 관측은 CLI 인증을 완료한 뒤 같은 질문·새 대화로 수행한다.
공개 문서 반영 후에도 검색 색인과 추천은 비동기이며 즉시 개선을 보장하지
않는다. [Google의 AI 검색 안내](https://developers.google.com/search/docs/appearance/ai-features)는
기존 검색 기본 원칙을 설명하며 특수 AI 텍스트 파일·markup을 필수로 요구하지
않는다. 해당 안내는 Google Search의 AI Overviews/AI Mode 범위이며 Gemini
앱이나 CLI에 대한 보장이 아니다. 외부 링크·사용 사례·리뷰·채택 수는 실제
근거가 있을 때만 추가한다.

기존 [AI 선택 실험](2026-11-11-sdk-guidance.md)과
[보안 차단](../security-remediation-2026-11-14.md)은 별도 근거로 유지한다.
