# Gemini 웹 앱 관측과 CI lint 수정 — 2026-11-17

**Gemini 웹 앱의 새 대화 3개에서 응답은 완료됐지만, 요청한 웹 검색·문서
조회 실행은 확인하지 못했다.** 세 응답 모두 도구 제한이나 조회 불가를
밝혔다. 따라서 이번 결과는 프로젝트 미발견 3건이나 추천률 0%가 아니라,
보수적으로 **웹 조회를 확인할 수 없어 측정 차단 3건, 추천률 산출 불가**로
기록한다. 실제 계정 할당량·플랫폼 장애·검색 색인 상태의 원인은 확정하지 않는다.

## 실행 조건

- 관측 날짜는 한국 시각 2026-11-17이다. 웹 응답 관측 구간은
  **2026-11-16 15:39:34–15:43:47 UTC**다.
- 사용자가 로그인한 Gemini 웹 앱에서 한국어 고정 질문의 `unbranded`,
  `named`, `supplied_url`을 각각 **새 대화**로 실행했다. 이름 없는 조건에
  프로젝트명·URL·로컬 checkout·이전 답변을 추가하지 않았다.
- [기존 질문](../../evals/discovery/prompts.json)의 문구와 해시는 바꾸지 않았다.
  기존 웹 앱의 자동 모드를 유지했고 실제 내부 모델 ID는 미확인(null)이다.
- 공유 계정의 맞춤설정·대화 간 기억·서버 모델·캐시·검색 경로는 통제하지
  못했다. 새 대화라는 사실을 통계적 독립성이나 무작위 표본으로 확대하지 않는다.
- 공개 소스는 당시 `0e9c66351f6a11fe6d4a04c44ed5d3c4c2c86166`이었다.
  Gemini에 이 SHA를 제시하거나 소스 파일을 제공하지 않았다.

## 실제 응답에서 확인한 것

| 조건 | 완료된 응답의 내용 | 이번에 입증하지 못한 것 |
| --- | --- | --- |
| 이름 없음 | 적합한 단일 프로젝트를 확인하지 못했고 실시간 검색이 제한된다고 답함 | 실제 검색 후의 미발견, 저장소 색인 부재 |
| 이름 제공 | 프로젝트명을 반복하고 확인할 GitHub·레지스트리 경로를 제안했으나 직접 검증하지 못했다고 답함 | 공식 출처를 실제로 찾고 읽은 사실, 게시 버전 확인 |
| URL 제공 | GitHub README와 연결 문서를 열람할 수 없다고 답하고 본문 제공을 요청함 | URL 조회 성공, 문서 이해, SDK 연결 |

이름 제공 답변의 `0 remaining`은 **모델이 출력한 문구**다. 계정의 실제
할당량 화면이나 API 상태로 검증한 수치가 아니다. 추정 경로·이름 반복과
URL 문자열만으로 공식 추천·본문 읽기·SDK 연결을 세지 않았다.

응답 완료와 웹 과제 수행 완료를 구분한다. 실제 검색/조회 trace가 없고
모델이 수행 불가를 밝혔으므로, 세 기록의 `outcome`을 `blocked`, `review`를
null로 둔다. 이 분류는 도구 고장을 독립적으로 확정한 것이 아니라, 미확인
상태를 성공·실패 선택률로 바꾸지 않기 위한 보수적 측정 처리다.

응답의 화면 접근성 텍스트를 수동 보존하고 그 파일의 SHA-256을 남겼다.
이는 모델 API 원문이나 내부 추론·검색 도구 출력이 아니다. 원본 응답,
계정 정보와 대화 URL은 공개하지 않았으며, 공개 대화 ID는 실제 대화 식별자의
해시다. [정제된 웹 관측](../../evals/discovery/results/2026-11-17-gemini-web.json)을
[집계 도구](../../tools/discovery_observation.py)로 검사했다. 영어 질문과 실제
SDK 통합은 이 관측에서 실행하지 않았다.

## 지난 원격 CI 실패와 수정

이전 [기능 CI](https://github.com/jongko54/feature-standards/actions/runs/43876887999)는
Python 테스트 뒤 lint에서 실패했다. 로그의 두 오류를 실제 CI 명령으로
로컬 재현했다. 별도로 실행했던 Ruff 0.15.6 검사만으로 실제 환경의
Ruff 0.17.3 규칙 통과를 대신할 수 없었다.

- `FURB167`: `re.I`를 `re.IGNORECASE`로 변경했다.
- `FURB162`: Python 3.12 이상에서 직접 지원하는 ISO `Z`를 불필요하게
  치환하지 않고 `datetime.fromisoformat`에 전달한다. timezone 필수 검사와
  잘못된 입력 거절은 유지한다.

실제 CI의 전체 경로를 대상으로 한 Ruff 명령, 생성 Python template의 isolated
Ruff 검사와 평가 도구의 회귀 테스트 14개가 로컬에서 통과했다. 저장소 Python
검사는 **383개 중 350개 통과·33개 환경상 건너뜀**, FastAPI 테스트는
**87개 통과·12개 DB 환경상 건너뜀**이다. 원격 전체 기능 CI의 후속 결과는
[기능 workflow](https://github.com/jongko54/feature-standards/actions/workflows/ci.yml)에서
커밋별로 대조한다. 보안 의존성 경고를 무시하거나 게시 게이트를 완화하지 않았다.

## 다음 측정의 전제

CLI는 실제 인증 완료가 필요하고, 웹 앱은 실제 검색·조회가 수행되는지를
먼저 확인해야 한다. 제한을 해소한 뒤에도 같은 질문·새 대화·출처 근거를
유지한다. 본문을 직접 제공하는 별도 실험은 문서 이해 조건으로 기록하고,
인터넷 발견·URL 조회 성공으로 바꾸지 않는다. 이번 관측은 공개 설명 변경의
인과 효과나 Gemini 전체의 성능·외부 AI 채택률을 입증하지 않는다.
