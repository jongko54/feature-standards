# 외부 파일 고지

`mvnw`와 `mvnw.cmd`는 Apache Maven Wrapper 3.3.4의 공식 스크립트입니다. 원본의 Apache License 2.0 헤더를 보존하며 [LICENSE](.mvn/wrapper/LICENSE)와 [NOTICE](.mvn/wrapper/NOTICE)를 함께 포함합니다. 이 파일들의 라이선스는 저장소의 자체 코드에 적용되는 MIT 라이선스와 구분됩니다.

원본: https://github.com/apache/maven-wrapper/tree/maven-wrapper-3.3.4

참조 구현이 사용하는 라이브러리는 Maven으로 가져오며 이 저장소에 라이브러리 바이너리를 재배포하지 않습니다.
